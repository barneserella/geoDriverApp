geoDriverApp

Tracks user driving locations in real time and detects anomalies in driving behaviour (e.g. sudden speed changes, erratic routing, unexpected stops) using geospatial analysis.

Tech Stack <br>
Node.js — runtime <br>
TypeScript — type-safe application code <br>
Express — REST API framework <br>
PostgreSQL — primary database <br>
PostGIS — geospatial extension for location queries and spatial analysis <br>
Prisma — ORM and database migrations (using the @prisma/adapter-pg driver adapter) <br>
tsx — TypeScript execution for local development <br>
dotenv — environment variable management <br>
