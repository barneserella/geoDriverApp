geoDriverApp

Tracks user driving locations in real time and detects anomalies in driving behaviour (e.g. sudden speed changes, erratic routing, unexpected stops) using geospatial analysis.

Tech Stack
Node.js — runtime
TypeScript — type-safe application code
Express — REST API framework
PostgreSQL — primary database
PostGIS — geospatial extension for location queries and spatial analysis
Prisma — ORM and database migrations (using the @prisma/adapter-pg driver adapter)
tsx — TypeScript execution for local development
dotenv — environment variable management
